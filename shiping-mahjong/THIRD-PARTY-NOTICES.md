# 第三方素材及致谢

本项目采用了 [tiansh/tjmj](https://github.com/tiansh/tjmj) 项目中使用的麻将牌面图 URL（目录为 `tp/w`、`tp/b`、`tp/t`、`tp/z` 和 `tp/h.png`）。牌图来源说明见该项目 `index.html`：牌面由 Jerry Crimson Mann 绘制，来自 Wikipedia。

牌面图以 CSS `url()` 直接引用上游 GitHub 原始文件，没有将图像文件重新打包进本仓库。原项目代码声明 GPL v3；本项目规则引擎和页面代码采用 GPL-3.0-or-later。对每张 Wikipedia 图片的单独文件许可，仍应以其原始 Commons/Wikipedia 文件页标注为准；本项目不对未核实的图片许可作额外声明。
